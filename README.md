# Nodexy

Десктопное приложение для точного учета времени, проведенного в различных программах на Windows.

## Особенности

- **Точный учет**: засчитывает время только когда приложение активно (в фокусе и есть ввод с клавиатуры/мыши)
- **Фоновый режим**: опциональный подсчет времени для запущенных приложений даже в фоне
- **Порог простоя**: периоды без активности дольше заданного времени не засчитываются
- **Автоматическое определение**: находит установленные приложения через реестр, меню Пуск, Steam и запущенные процессы
- **Интерфейс в стиле Steam**: темная тема, удобные карточки приложений
- **Иконки приложений**: автоматическая загрузка и отображение иконок

## Установка

**Основной способ — установщик.** Скачайте `Nodexy-Setup-<версия>.exe` со
страницы [релизов](https://github.com/DippyDingo/active-tracker/releases) и
запустите его:

- Права администратора **не нужны**: установка идёт только для текущего
  пользователя, по умолчанию в `%LOCALAPPDATA%\Programs\Nodexy`.
- Каталог установки можно выбрать любой (кроме `Program Files` и `Windows` —
  папка должна быть доступна на запись, иначе автообновление не сможет
  заменять файлы).
- Мастер предложит ярлыки в меню Пуск/на рабочем столе и автозапуск при входе.
- Удаление — штатно, через «Приложения и компоненты».

> **SmartScreen.** Установщик пока не подписан сертификатом. Если при первом
> запуске Windows покажет «Система Windows защитила ваш компьютер», нажмите
> «Подробнее» → «Выполнить в любом случае».

**Портативный вариант** — `Nodexy-portable-<версия>.zip` (внутри `Nodexy.exe`)
или голый `Nodexy.exe` из ассетов релиза: распакуйте в любую папку и запустите.

**Запуск из исходников:**

1. Установите Python 3.13+
2. Создайте виртуальное окружение:
   ```bash
   python -m venv .venv
   ```
3. Активируйте его:
   - Windows: `.venv\Scripts\activate`
4. Установите зависимости:
   ```bash
   pip install -r requirements.txt
   ```
5. Запустите:
   ```bash
   python main.py
   ```

## Использование

Запуск установленного приложения: ярлык «Nodexy» в меню Пуск или
`%LOCALAPPDATA%\Programs\Nodexy\Nodexy.exe`. Портативной версии —
соответствующий `Nodexy.exe`.

При первом запуске приложение предложит создать новую базу данных или загрузить ранее сохранённую.

## Сборка

- **Собственный exe**: запустите `build_exe.bat` (нужен установленный в
  `.venv` пакет `pyinstaller`). Результат — `dist\Nodexy.exe`.
- **Установщик**: нужен [Inno Setup 6](https://jrsoftware.org/isinfo.php)
  (`winget install JRSoftware.InnoSetup`), затем:
  ```bash
  tools\build_installer.ps1
  ```
  Скрипт соберёт `dist\Nodexy.exe`, установщик
  `dist-installer\Nodexy-Setup-<версия>.exe`, портативный
  `dist-installer\Nodexy-portable-<версия>.zip`, посчитает SHA256 всех
  артефактов и напечатает, какая сумма идёт в тело релиза.
- **Автоматически**: пуш тега `v*` запускает CI
  (`.github/workflows/release.yml`) — сборка, проверка совпадения версии с
  тегом и публикация релиза с ассетами.

## База данных

- Текущая база хранится по пути из конфига: `%APPDATA%\ActiveTracker\config.json`
- **Экспорт базы** — меню (три полоски справа вверху) → «Экспорт базы данных»
- **Загрузка базы** — меню → «Загрузить базу данных» (файл `.db`, проверяется на корректность)

Это позволяет перенести статистику на другой компьютер или сохранить резервную копию.

## Основные функции

- Добавление приложений из списка установленных программ
- Добавление приложений по пути к .exe файлу
- Настройка порога простоя (1-240 минут)
- Включение/выключение учета времени в фоне
- Просмотр статистики по каждому приложению
- Сворачивание в системный трей

## Хранение данных

Данные сохраняются в SQLite базе данных по пути:
`%APPDATA%\ActiveTracker\tracker.db`

## Требования

- Windows 10/11
- Python 3.13+
- Доступ к Win32 API
