# Файлы

- [Установка обновления, откат и защита от зацикливания](install-and-rollback.md) - Как REDIS применяет скачанное обновление — состояние update_pending и счётчик попыток, отделение штатного выхода от падения в boot_check, критерии отката, планирование установки через helper, маркер install.lock и очистка осиротевших процессов.
- [Проверка обновлений и загрузка релиза](update-system.md) - Как REDIS узнаёт о новых версиях — сравнение версий, запрос релизов GitHub, стратегия выбора только установщика, объединение заметок нескольких пропущенных версий, скачивание с прогрессом, блокировка параллельных загрузок и проверка SHA256.
- [Отдельный процесс-обновлятор](updater-helper.md) - Устройство REDISUpdater.exe — перенос собственного исполнения в %TEMP%, ожидание выхода приложения по PID и по имени exe, запуск установщика Inno Setup без оболочки, выбор запускаемого файла после переименования и порядок снятия маркера установки.
